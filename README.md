# homework-16

# Описание

Мини-приложение для практики **современного React Router (v7)**, защищённых маршрутов, вложенных страниц и загрузки данных через `loader`.

## Технологии

- **Vite**
- **React**
- **TypeScript**
- **React Router DOM**
- **LocalStorage**

## Функциональность

- Главная страница `/`
- Страница логина `/login` с формой:
  - email
  - password
- Защищённый маршрут `/dashboard`:
  - доступен **только после логина**
  - иначе автоматический редирект на `/login`
- Вложенные маршруты:
  - `/dashboard/profile` — профиль пользователя
  - `/dashboard/settings` — изменение имени
  - `/dashboard/stats` — загрузка данных из API через `loader`
- Навигация между вкладками без перезагрузки
- Страница `404` для несуществующих маршрутов

## Авторизация

- Состояние авторизации хранится в `localStorage`:
  - `isAuthenticated`
  - `userName`
  - `userEmail`
- После логина пользователь автоматически перенаправляется:
  - либо обратно туда, откуда пришёл,
  - либо на `/dashboard`

## Структура проекта

```bash
src/
  layouts/        # RootLayout и DashboardLayout
  pages/          # Все страницы приложения
  routes/         # ProtectedRoute
  loaders/        # Loader для Stats
  router.tsx      # Конфигурация маршрутов
  main.tsx        # Точка входа
```

## Установка и запуск

```bash
npm install
npm run dev
```
